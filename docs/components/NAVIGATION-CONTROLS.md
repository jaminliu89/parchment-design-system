# Navigation Controls

## Purpose

Navigation controls provide predictable movement and context switching across Parchment workspaces.

## Components

- Tabs
- Segmented Control
- Menu
- Breadcrumb
- Command Menu
- Navigation Item

## Rules

Navigation communicates location and action. It must not compete with creative content.

## States

All navigation controls define:

- default
- hover
- focus
- active
- selected
- disabled

## Constraints

Do not create custom navigation patterns inside product screens. Extend existing patterns only when a documented workflow requires it.
