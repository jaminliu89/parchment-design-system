# Surfaces and Data Display

## Purpose

Reusable containers and information display primitives for creator workflows.

## Components

- Card
- Panel
- Table
- List
- Divider
- Avatar
- Badge
- Status Indicator

## Rules

Surfaces provide hierarchy, not decoration.

Avoid excessive cards, floating containers, and unnecessary borders.

Every surface must define:

- content hierarchy
- density
- interaction state
- responsive behavior
