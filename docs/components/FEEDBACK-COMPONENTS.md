# Feedback Components

## Purpose

Feedback components explain system state without interrupting creative flow.

## Components

- Tooltip
- Popover
- Toast
- Alert
- Progress
- Spinner
- Skeleton
- Empty State
- Error State

## Principles

- Status must be understandable without relying only on color.
- Errors provide recovery guidance.
- Loading states preserve layout stability.
- Empty states explain the next useful action.

## States

Every applicable component defines:

- idle
- loading
- success
- warning
- error
- disabled
