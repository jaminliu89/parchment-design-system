# Parchment Responsive Audit

## Principle

Responsive design prioritizes user intent, not shrinking desktop layouts.

## Desktop

- Full navigation
- Workspace canvas
- Inspector panel

## Tablet

- Collapsed navigation
- Canvas remains primary
- Secondary panels become drawers

## Mobile

- Content first
- Primary actions reachable
- Secondary configuration moved to sheets/drawers

## Rules

- Do not duplicate mobile-only components without need.
- Preserve information hierarchy across breakpoints.
- Keep touch targets accessible.
