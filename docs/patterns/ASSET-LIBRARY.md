# Parchment Pattern — Asset Library

## Purpose

Provide a consistent way to browse, organize, inspect, and act on creative assets.

## Asset anatomy

```
Preview
 ↓
Metadata
 ↓
Actions
 ↓
State
```

## Supported views

- grid
- list
- detail preview

## Required capabilities

- search
- filtering
- sorting
- selection
- bulk actions
- metadata display
- loading state
- empty state
- error state

## Visual rules

Assets are content. The UI should support discovery without competing with the creative work.

Avoid excessive cards, badges, and decorative containers.
