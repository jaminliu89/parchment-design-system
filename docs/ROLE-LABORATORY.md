# Parchment Role Laboratory

## Purpose
Define role-based experiences without creating separate visual systems.

## Roles

### Creator
Flow: Idea → Plan → Create → Publish

Priorities:
- fast entry into creation
- clear next action
- low cognitive overhead

### Director
Flow: Vision → Structure → Review → Decision

Priorities:
- project overview
- milestones
- decisions

### Editor
Flow: Material → Timeline → Revision → Export

Priorities:
- precision
- dense but readable information
- reliable states

### AI Assistant
Flow: Intent → Capability → Suggestion → Human Decision

AI must enhance workflow, not replace user control.

### Reviewer
Flow: Inspect → Comment → Approve

## Rule
Roles may change priorities, never tokens or component contracts.
